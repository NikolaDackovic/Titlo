# Titlo: ime proizvoda i nazivi

| | |
|---|---|
| Ime | **Titlo** (ranije „ExYu Titl Studio“) |
| Kratak opis | Subtitle & Localization Studio · *Studio za titlove i lokalizaciju* |
| Tagline | *Your words. Every language. Perfectly timed.* · *Vaše reči. Svaki jezik. Savršeno tempirano.* |
| Opis | Local-first subtitle editing, transcription and localization studio |

**Zašto „Titlo“.** Korisnici su iz Srbije, Hrvatske i Bosne i Hercegovine. Ime je isto u sva tri jezika i u
engleskom, nema dijakritika (fajlovi, linkovi, tastature) i ne sadrži reč koja se razlikuje po jatu ili
između varijanti (reč/riječ, prevod/prijevod). Predloženo ime „Sublyra“ korisnik je odbio.

## Vizuelni identitet

- Postojeći raspored Studija ostaje (traka, leva navigacija, pregled, inspektor, timeline).
- Znak: belo „T“ iznad dve linije titla na ljubičastoj podlozi (`#7c6cf0`). Fajlovi:
  `public/favicon.svg` i `src/ui/components/BrandMark.tsx` (isti crtež). Znak više nema gradijent.
- Tamna grafitna osnova i ljubičasti akcent su postojeći tokeni (`src/styles/base.css`). Bez ilustracija.
- Statusi originala koriste postojeće boje u vidu tanke ivice ili tačke (vidi
  `docs/TRANSCRIPTION_QUALITY_CONTROL.md`).

## Nazivi u interfejsu

| Ranije | Sada (SR) | Sada (EN) |
|---|---|---|
| Glosar (stranica, navigacija, inspektor, izvor predloga) | Terminologija | Terminology |
| glosar (pojedinačni skup termina) | lista termina | term list |
| Ciljni termin (za vrstu „Terminologija“) | Preporučeni prevod | Preferred translation |
| — | Alternativni prevodi, Kategorija | Alternative translations, Category |
| Početni glosar (EN), za nove baze | Starter terminology (EN) | Starter terminology (EN) |

Postojeće baze zadržavaju ime koje je lista termina već imala (npr. „Starter glossary (EN)“), jer su to
korisnički podaci.

## Šta namerno nije promenjeno (kompatibilnost)

| Identifikator | Zašto ostaje |
|---|---|
| IndexedDB baza `exyu-titl-studio`, localStorage `exyu-titl-studio-projects`, `exyu.timelineHeight` | promena bi „izgubila“ postojeće projekte i podešavanja |
| Web Lock `exyu-titl-studio-database` | stari i novi tab moraju da dele isto zaključavanje |
| ID profila `exyu-neutral` i naziv profila „ExYu Neutral“ | jezički profil (ne ime proizvoda) i ključ u bazi |
| `EXYU_MODELS_DIR`, `%LOCALAPPDATA%\ExYuTitlStudio\models` | modeli su već instalirani tamo |
| Tabele `glossaries`/`glossary_terms`, folder `src/glossary`, tip `GlossaryTerm` | interni nazivi; promena bi zahtevala migraciju bez koristi |
| npm paket `exyu-titl-studio`, dataset `exyu-translation-100`, istorijski rezultati benchmarka | interni ili istorijski podaci |

Izvoz baze sada se zove `titlo-YYYY-MM-DD.sqlite`, JSON izvoz termina ima `"format": "titlo-terminology"`, a
ASS zaglavlje kaže „Script generated by Titlo“. Uvoz prihvata i fajlove iz starijih verzija.

Test `src/branding.test.ts` proverava da se staro ime i „Glosar/Glossary“ ne pojavljuju u interfejsu
(SR i EN) i da su interni ključevi zadržani.
